# TravelVista

TravelVista is a simple travel website built with HTML and basic CSS. It shows popular destinations, hotels, restaurants, and a contact footer.

## Features

- Travel and destination sections
- Popular hotels and restaurants
- Destination, budget, and rating search fields
- Responsive layout for mobile devices
- Navigation links to page sections

## Files

- `index.html` - Website structure and content
- `style.css` - Website styles and responsive layout

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Open this project folder.
2. Open `index.html` in a web browser.
3. You can also use Live Server in VS Code.
